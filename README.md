# 🐈 Orange Cat Lotto System
A comprehensive, full-stack web application designed for lottery management. This system streamlines ticket inventory tracking, real-time sales management, automated bonus checking, and shipment tracking. Built with scalability and security in mind to support seamless administrative operations.

## 🛠 Tech Stack

### Frontend
- React.js: Modular UI components for a smooth user experience.
- Bootstrap 5: Responsive design and layout management.
- SweetAlert2 & React-Toastify: Professional-grade notifications and alerts.
- Day.js: Precise date and time manipulation for financial reports.

### Backend & Database
- Node.js + NestJS: Robust and scalable backend architecture.
- PostgreSQL (Supabase): Cloud-native relational database for reliable ticket and transaction storage.
- Prisma ORM: Type-safe database queries.
- JWT (JSON Web Token): Secure authentication and role-based access control.
- Docker: Containerization for simplified deployment and environment consistency.

### Deployment & Cloud Infrastructure
- Vercel: Lightning-fast frontend hosting with automated CI/CD pipelines.
- Render: Reliable cloud platform for deploying the robust NestJS backend.
- Supabase: Managed cloud database providing secure, highly available PostgreSQL storage and connection pooling.

## 🚀 Key Features

- Inventory Dashboard: Real-time insights into total sales, profits, and stock levels.
- Automated Results Tracking: Fetches official lottery results and matches tickets automatically.
- Ticket Lifecycle Management: From stock entry and pricing to shipping and payout verification.
- Role-Based Access (Admin/Staff): Secure user management and profile control.
- Dynamic Content Management: Multi-position floating and slider banners for promotions.
- Financial Reporting: Automated income and profit calculations with date-range filters.
